# Java Basics

## Arrays 

### 1. What is an Array?

An array is a set of uniform data elements that can be accessed using indexes.

    An element is a single item in an array.
    Uniform means that all elements in a given array must have the same data type.
    The index of an element refers to its position in the array. (Array indexes start at 0!)

Arrays can have any number of dimensions. A one-dimensional array is a vector, a two-dimensional array is a table, and a three-dimensional array is a cube. We use the term rank to describe the number of dimensions in an array.

Each dimension in an array has a length, which describes the number of positions in that direction. For example, in the case of a two-dimensional table with 2 rows and 6 columns, one dimension would be of length 2 and the other would be of length 6.

![2rows with 6 columns](/images/2rows%20with%206%20columns.png)

The length of the array itself is the total number of elements in all dimensions. So, our table above would have an array length of 12 (6 rows * 2 columns).

The index of each element in an array is an integer that refers to a specific element space in the array. Indexes in most modern programming languages start with 0. For example, in our two-dimensional table, the element in the 2nd row, 3rd column would be located at index [1][2].

#### 1.1. Types of Arrays

We can create three types of arrays.

The first type is the one-dimensional array. This can be thought of as a single line or, in math terms, a vector of elements.

![one-dimensional array](/images/One%20Dimensional%20Array.png)

Second, we have a multidimensional rectangular array, which is structured like a two-dimensional table. In these arrays, all of the subarrays have the same length.

The following diagram shows a two-dimensional array with six columns and three rows:

![Multi-dimensional Array](/images/Multi-dimensional%20Array.png)

If we add another subarray to this array, we have a three-dimensional array:

![Overlapping](/images/Overlapping.png)

Third, and last, we have the multidimensional jagged array, in which each subarray is a single independent array and, as such, can have different lengths.

Unlike some languages (such as JavaScript), the array size is fixed in Java. This means that after you instantiate an array and specify its dimension and lengths, those lengths cannot be changed. Additionally, while you can go beyond three-dimensional arrays, this is typically unnecessary and gets confusing. As a result, we generally err on the side of simpler data structures.

#### 1.2. Element versus Index

As indicated earlier, it is important to be able to distinguish between the data stored in the array (the elements of the array) and the integers that define where that data is stored (the indexes of the array).

One metaphor that can help you keep the distinction in mind is that of houses on a street. Each house has a numeric address on the street, but the house is not the same thing as the address (and similarly, the address is not the same thing as the house). The address (index) allows us to go to the right part of the street (array) and view the house (element) at that location.

### 2. Declaring Arrays

The syntax for declaring an array variable depends on the shape of the array to be created.

#### 2.1. Single Dimensional Arrays

The declaration of the array variable is simplest for single dimensional arrays. You must simply provide the type of the elements to be stored, followed by square brackets.

        int[] arrayOfInts;  //creates a one dimensional array

#### 2.2. Rectangular Arrays

Rectangular arrays are also relatively simple. To add another dimension to the array you simply add another set of square brackets to the declaration. Each set of brackets will determine the dimension of the array, [ ] for one dimension, [ ][ ] for two dimensions, and so on.

The following code will create multi-dimensional arrays.

        int[][] my2DArray = new int[4][4];                 //creates a 2 dimensional array that will hold (4 X 4) 16 elements.
        int[][][] my3DArray = new int[5][5][5];            //creates a 3 dimensional array that will hold (5 X 5 X 5) 125 elements.
        String[][] myJaggedStringArray = new String[2][4]; //creates a jagged 2 dimensional array that will hold (2 X 4) 8 elements.

#### 2.3. Jagged Arrays

Jagged arrays are arrays of arrays and as such, the syntax for declaring variables of that type will involve multiple square brackets to indicate the nesting of arrays.

        public static void jaggedArray() {
            String[][] strArray = {{"This", "is"}, {"a", "test", "of", "jagged arrays"}};
        
            for (int i = 0; i < strArray.length; i++) {
                for (int j = 0; j < strArray[i].length; j++) {
                    System.out.print(strArray[i][j] + " ");
                }
                System.out.println();  
            }
        }

### 3. Initializing Arrays

Under the hood, arrays are simply blocks of memory, just like any other variable. This means we can initialize an empty array and add elements to it later, or we can initialize an array that already includes the elements we want the array to hold.

If we initialize an empty array, we simply specify the number of elements we wish to allocate space for without providing the data to be stored immediately. Depending on the data type, default values will be placed at each location in the array.

In the other method of initialization, we can provide data right away and the size of the array will be inferred and set to exactly the size required for that data.

Keep in mind that you cannot change the size of an array after it has been initialized. This means that you must define the size correctly when you initialize an array, even if the elements themselves are initially empty. This is one reason to take time to plan out an array on paper before coding it.

#### 3.1. Initializing a Single Dimensional Array

As with declaration, initialization is simplest with single-dimensional arrays.

        // create a new array with 4 elements (default 0 for int)
        int[] numbers = new int[4];
        
        // same array, specifying element values
        int[] numbers = { 0, 0, 0, 0 };
        
        //same array, using a slightly older (and more verbose) syntax
        //NOTE: this is outdated, but you may see code like this in the wild
        int[] numbers = new int[] { 0, 0, 0, 0 };

If we were to visualize this array after any of these statements has been executed, it would look like this:

![Simple Dimentional Array](/images/Single%20Dimensional%20Array.png)

#### 3.2. Initializing a Rectangular Array

If we want a tabular data structure (two-dimensional array), instead of putting a single number like the 4 above, we declare it as an int[][] (with brackets to define the dimension of the array) and then we put both dimensions in the brackets when we initialize it. The following code would create an array with 2 rows and 3 columns:

        int rows = 2;
        int columns = 3;
        int[][] table = new int[rows] [columns];
        // could also be written as new int [2][3]

This would produce an array of default int values:

![Rectangular Array](/images/Rectangular%20Array.png)

> The designation of first dimension as a "row" and the second as a "column" is arbitrary. Arrays don't have a spatial layout: they're just memory locations with numeric addresses. We could have just as easily made the first dimension the "column" and the second be the "row". However, when you work with multi-dimensional arrays, it will be critical for you to establish and maintain consistent conventions accross your application.

As with single-dimensional arrays, multi-dimensional arrays can be auto-initialized. The following code creates the same two-dimensional array, but with values in each element:

        //                          row 0        row 1
        int[][] autoInitTable = { { 5, 3, 1 }, { 2, 4, 6 } };

![Rectangular Array 2](/images/Rectangular%20Array%202.png)

In this setup, each "row" in the array is a separate subarray, and each subarray includes the same number of elements.

#### 3.3. Initializing a Jagged Array

Unlike the two-dimensional array described above, a jagged array includes multiple arrays of varying lengths. As a result, jagged arrays do not have a regular shape and initialization is slightly trickier.

Jagged arrays are actually arrays of arrays (or in the case of three-dimensions, arrays of arrays of arrays).

        // array with 3 elements that are each an array
        // another jagged array example
        int[][] jagged = new int[3][];
        
        jagged[0] = new int[] { 1, 2 };
        jagged[1] = new int[] { 3, 4, 5, 6 };
        jagged[2] = new int[] { 7, 8, 9 };

Here is a visualization of the jagged array created by this code:

### 4. Accessing Array Elements

To access an individual element, we simply use the index of the element we want to work with inside square brackets. The trickiest part for beginners is remembering that indexes start from zero! So, if you want the first element, it is at index zero [0].

As an example, let’s consider our one-dimensional array example:

        int[] numbers = new int[] { 3, 5, 2, 0 };

![Accessing Array Element](/images/Accessing%20Array%20Elements.png)

> Don't confuse the index of an element with its value. The second element in this array has the index 1 and the value 5.

Here is how we could print the element currently in index 2 (3rd slot) and replace the element in index 3 (4th slot) with another value:

        int[] numbers = new int[] { 3, 5, 8, 9 };
        // indexes                  0  1  2  3
        
        System.out.println(numbers[2]); // prints 8
        
        numbers[3] = 7; // replace 9 with 7 in the fourth element

#### 4.1. Accessing Elements in a Multidimensional Array

As you increase the number of dimensions in the array, simply place the index in a bracket for each dimension.

![Accessing Multi-Dimentional Array](/images/Accessing%20Multi%20Dimensional%20Array.png)

        // 1st row, 2nd column
        int three = autoTable[0][1];
        
        // 2nd row, 3rd column
        int six = autoTable[1][2];

### 5. Iterating through Arrays

Arrays and loops go hand in hand. Any time you want to read through multiple elements of an array, in particular when the incoming arrays could have different lengths, you will need to "loop" through it.

> Depending on the type of loop, this means either looping through the valid indexes of the array and using the indexes as shown above to access the elements at those locations or it means iterating through the elements directly.  
> When performing the second kind of loop, we will not know what index we're on at any given time. We don't typically need to know the index, but there are cases when we do need this information.

Below are a series of examples of some techniques for iterating through arrays. They are good templates to study. We encourage you to type them into a console application and debug them to see how they work.

#### 5.1. Sum the Elements of an Array

Let’s say we wanted to find the sum of an array of integers. We can use the length of the array to determine the number of times we loop through the array. Remember that length refers to the number of elements in the array, so an array's length is always 1 less than the highest index in the array.

We could write the code like this:

        int[] numbers = {3, 5, 2, 1};
        int sum = 0; // keep running total
            for (int i = 0; i < numbers.length; i++) {
                sum += numbers[i];
                System.out.println("i = " + i + " current sum = " + sum);
            }
        System.out.println("Final sum: " + sum);

The output is:

        i = 0 current sum = 3
        i = 1 current sum = 8
        i = 2 current sum = 10
        i = 3 current sum = 11
        Final sum: 11

#### 5.2. Looping Back to Front, With a Twist

In Java, a for loop can count up or down, so we can also loop through an array from back to front if we wish. LIn fact, let’s go from back to front and print only the elements that are in odd-numbered indexes:

        int[] numbers = {3, 5, 2, 0};
        // start at last index, go to first (0)
        for (int i = numbers.length - 1; i >= 0; i--) {
            if (i % 2 == 1) {
                System.out.println("index " + i + " - " + numbers[i]);
            }
        }

The output of this code would be:

        index 3 - 0
        index 1 - 5

#### 5.3. Printing Pairs of Elements

For this example, let’s consider that we want to print pairs of elements, skipping one number in between each pair. So if we have an array with numbers 1, 2, 3, 4, 5, 6, we want to print 1,2 then 4,5:

        int[] numbers = {1, 2, 3, 4, 5, 6};
    
        for (int i = 0; i < numbers.length - 2; i += 3) {
            System.out.println("Pair: (" + numbers[i] + ", " + numbers[i + 1] + ")");
        }

There are three key ideas in this sample:

1. For each printout, we include two numbers and skip one number. This means using three elements in each loop. Thus, our increment for the loop needs to be i += 3. 
2. Since we are reading three elements in, we need to stop earlier than length. i < numbers.Length works for one element at a time, but since we have 3 we need to subtract the difference (3 - 1 = 2). 
3. We can use an expression as an index. So [i + 1] is the index next to the current element i.

As always, be sure to write pseudocode, flowchart the process, or simply write the steps of the process out with sample data before attempting to code. The majority of times we assist students with array issues, it is because they have not solved the problem on paper before writing code.

### 6. Changing the Size of an Array

Although we can't directly change the size of an array, we can initialize a new, larger array and copy all of the elements over to it:

        public int[] GrowArray(int[] original, int howManyMoreElements) {
            int[] newArray = new int[original.length + howManyMoreElements];
            
            for (int i = 0; i < original.length; i++)
            {
                // copy the element at the current index
                // from original to newArray
                newArray[i] = original[i];
            }
        
            return newArray;
        }

We again use a for loop to iterate through the elements of the original array and use the original indexes to map the elements to the same locations in the new array.

### 7. Dealing with Errors

Index out of range exceptions are the most common exceptions you encounter when dealing with arrays. Simply put, this error occurs when you try to access an element of an array that does not exist:

        int[] numbers = {1, 2, 3, 4, 5, 6}

        // index out of range exception, there are only 6 elements so the max index is 5
        System.out.println(numbers[52]);

This error only occurs at run time and when iterating through an array, the error usually means that your i < {expression} in your for loop is incorrect.

In our previous example of growing an array, if the howManyMoreElements had been negative when our for loop was set to loop for each element in the original array, it would have had more indexes than the newArray. As a result, it would throw the ArrayIndexOutOfBoundsException once the loop progressed past the last element of newArray.
