# REST Web Services

## Web Applications

### 1. From Network Applications to Web Applications

A network application is an application that includes content from two or more servers. For example, when we build an application that connects to a database server, we create a network application. Even when the database is installed locally (on the laptop or desktop we use for software development), it communicates over the network. Our applications would work just as well if the database was installed on a computer on the other side of town, or even the other side of the world.

At its simplest, network communication is a series of bytes transmitted through wires or air. Those bytes have rules for acceptable values and sequences. If our bytes are wrong, our "message" is ignored. To communicate, we must follow the rules. Those rules are called a protocol. In basic database applications, those rules are largely hidden from us. We write code that calls a database driver, and the driver is aware of protocols. The driver sends SQL across the network using a protocol. The database server receives it, runs the SQL, and sends a result back using a protocol.

Actually, there are two (or more!) protocols at work. The first is the database communication protocol. That's usually proprietary, meaning that the database vendor controls it. The other is a network protocol, often TCP. TCP is not proprietary. It's a shared standard which allows anyone to send messages that can be understood by computers around the world. The database communication protocol is sent over TCP. Protocols can be stacked or nested inside one another – a fact that we exploit to build web applications.

All web applications are network applications but not all network applications are web applications. A web application is a network application that uses open web protocols and standards to communicate and render its user interface. Using open standards makes it relatively easy to build web applications using any general-purpose programming language.

### 2. Web Application/Web Service

A web application is a network application that uses open web protocols and technologies. It's a broad category, with applications that range from rich UIs built using HTML, CSS, and JavaScript to largely invisible applications that shuffle data from place to place. Facebook is a web application. So is Amazon. The learning management system you're using to read this lesson is a web application.

A web service is a web application that manages data directly, without a user interface. All web services are web applications, but not all web applications are web services. A web service is a remote API. It can be used as a foundation to build other applications, from UI-based web applications to native mobile applications to desktop applications.

API stands for application programming interface. The goal of an API is to allow two or more computer programs to communicate with each other and share data.
