# Java Basics

## Loops

### 1. If/Else

Often when you're writing programs, you want the program to do something only IF something else is true. In Java, one way we 'control the flow' of the program is using if statements.

If statements operate using conditional expressions, which always evaluate to either true or false. To write conditions, you use conditional operators. There are a lot to choose from.

When you write an if statement, you declare the condition you want the program to check inside parentheses, followed by the code you want it to execute if the condition is true. If the condition is false, the program will just continue to the next step in the program, skipping the rest of the if statement completely.

The basic syntax looks like:

        if(condition) {
            // code
        }

We can string together a series of if statements to control the output of a program. Java will evaluate each statement in turn: if the current statement is true, it will perform the action specified in the statement and move on to the next if statement. If the current statement is false, C# will skip it and evaluate the next if statement or instruction.

While a basic if statement can be very useful, the problem is that each statement is evaluated independently of each other, meaning that any (or none or all) of the statements can produce an outcome, based on the input and conditions. Sometimes, though, we want the program to perform one action if the condition statement is true, and a completely different action if the conditional statement is false, without having to consider other conditions. For example, if it's raining, I'll need my rain boots. Otherwise, I'll wear my dress shoes. The condition is the same in both cases: only the output is different.

#### 1.1. If-Else Statements

This is where if-else is useful. With an if-else statement, we consider only one conditional statement and only one of the outcomes is possible. If we want multiple potential outcomes for the same condition, we can add multiple else statements. If we want to consider multiple conditions, we can include multiple if-else statements, each of which will be evaluated independently of the others and each of which can include multiple outputs.

        if(aliens > spaceships){
            System.out.println("Vrroom, vroom! Let's get going!");
        } else{
            System.out.println("There aren't enough green guys to drive these ships!");
        }

#### 1.2. AND / OR Operators

So far with our flow control, we've been using single part conditionals.

That is to say, we've been writing expressions that do a single comparison and evaluate to true or false. However, there are other options: conditional expressions can be compounded using ANDs or ORs.

With an AND operator, both conditions must be true for the conditional expression as a whole to be true. For example, If there is precipitation AND the temperature is below freezing, it will snow. If one or both of those conditions is false, it will not snow.

With an OR operator, the conditional expression is true if at least one of the conditions is true. If both are false, the conditional expression as a whole evaluates as false. For example, If it is raining OR snowing today (or even if it just cold enough to rain and snow at the same time), I will need an umbrella to stay dry if I go outside. The only case where I won't need an umbrella is if it is neither raining nor snowing.

Both AND (represented as &&) and OR (represented as ||) are logical operators. Code example:

        if (conditionA && conditionB) { //an AND condition 
            // code;
        }
        
        if (conditionA || conditionB) { //an OR condition
            // code;
        }

### 2. While & Dos

When you're a programmer, you can make the computer do some of the work for you. No one wants to write the same code over and over and over again. Loops are a fun way to clean up and code and make it DRY!

Let's start with while loops. The basic syntax looks like this:

        while(condition) {
            // CODE
        }

Basically, in a while loop, the condition is evaluated before each execution of the code block, including the first one, and the loop ends when the condition is false. So check the condition, if true - execute code and check the condition again. If false - skip.

#### 2.1. Do-While

There's another variant of the while loop, called the do-while. A do-while loop is almost identical to the while loop we talked about earlier, except that do-whiles get straight to business – executing their code block first and checking the condition to see if it should do it again only AFTER it's run once.

The syntax looks like this:

        do {
            // code
        } while (condition);

#### 2.2. Breaking a Loop

Sometimes when you're learning things, you have to go beyond your comfort level. But you always have to make sure you are self-aware enough to know when to stop and take a rest break.

Along with this life lesson, you get to learn more about loops. Because guess what, loops can stop when a programmer tells them to take a break! Literally. To stop a loop, use the break keyword!

Here's an example:

        while(condition) {
            if(othercondition) {
                break;
            }
        }

So while the loop would normally continue until the condition changed to false, now there is another way to bail out - if the "othercondition" ever evaluates to true - we stop the loop.

So, let's pretend we're diving in the ocean! We're going to keep going down, deeper and deeper, until the fish and everything gets too creepy, and we have to stop.

### 3. Fors

While loops are great, but there's another bread-and-butter looping syntax out there: the for loop. For loops are a bit different from while loops in that they define their beginning and ending points and incremental jumps. That makes for loops really good at incrementing, or iterating along set ranges.

A for loop includes 3 parts: an initialization, a stop condition, and an incrementation.

The basic syntax looks like this:

        for (int i = 0; i < 10; i++) {
            // code
        }

This for loop will execute its code block TEN times.

- It starts at 0 (>int i = 0;). 
- It increments by 1 every time (>i++). 
- It stops when >i < 10 is no longer true.

#### 3.1. Nesting For Loops

For loops are great. But loops WITHIN loops are even better. This is called nesting, and with nesting, a couple of small loops can execute a lot of code.
