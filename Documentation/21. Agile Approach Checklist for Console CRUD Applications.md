# Java Classes and Objects

## Agile Approach Checklist for Console CRUD Applications

### 1. Requirement Steps

#### 1.1 Step 0

Create user stories from the problem statement and/or requirements. For Address Book, it would be:

- Add an address 
- View an address
- Delete an address 
- Edit an address 
- List all addresses 
- Show the number of addresses in the address book 
- Save to file 
- Read from file

### 2. Design Steps

#### 2.1. Step 1

Analyze the problem statement and identify the required classes. For Address Book, we have the following:

- `Address` (DTO)
- `AddressBookDao` (data access object)
- `UserIO` (helper used by the View class to interact with the console)
- `View` class (used by Controller to handle user interaction)
- `AddressBookController` (this class orchestrates the program)
- `App` (this class has a main method that instantiates `AddressBookController` and calls the execute method)

#### 2.2. Step 2

Flesh out the classes by defining properties and methods for each.

#### 2.3. Step 3

Create a flowchart for the user interaction process (e.g., displaying menus and reacting to user menu choices).

#### 2.4. Step 4

Create file format to match the identified domain object(s) (e.g., Address). For example, for storing addresses, we might have something like this:

        <firstName>::<lastName>::<streetAddress>::<city>::<state>::<zip>

### 3. Construction Steps

#### 3.1. Step 5

Create a menu system (in the execute method of `AddressBookController`) with stubbed-out code for each menu choice. For example, when the user presses the choice to add an address, the system simply prints a message saying "AddAddress: To Be Implemented." This can be delivered to the user for testing and feedback.

#### 3.2. Step 6

Pick a user story to implement. For example: "Add address." For this story, we'll need to do the following:

- Create the Address class (domain object)
- Create the AddressBookDao class:
  - Include a HashMap or ArrayList to hold the Address objects as a class-level variable
  - Implement the addAddress(...) method
- Add code into the AddressBookController to:
  - Instantiate AddressBookDao object for storing Address information
  - Read in address information from the user
  - Create a new Address object
  - Put address information from the user into the Address object
  - Add the new Address to the AddressBookDao

Each user story will be different, and the first one is always the most work.

Repeat step 6 for each user story.
